# URL-Shortner
URL Shortener سرویسی است که یک آدرس اینترنتی طولانی را دریافت کرده و در ازای آن یک آدرس کوتاه و قابل‌استفاده در اختیار کاربر قرار می‌دهد.  در هنگام استفاده، کاربر با مراجعه به آدرس کوتاه، به آدرس اصلی (Original URL) هدایت (Redirect) می‌شود.  کاربرد این سامانه‌ها در به‌اشتراک‌گذاری لینک‌ها، مدیریت ترافیک و تحلیل بازدیدکنندگان بسیار رایج است.
